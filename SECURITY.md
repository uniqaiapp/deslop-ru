# Security

This repository contains a text-processing script with no network access, no dependencies and no execution of its input. The realistic risk is a pathological regex (catastrophic backtracking) on crafted input.

If you find one, or anything else, email support@uniqai.app with the input that triggers it. Please do not open a public issue first. You will get a reply within a few working days and credit in the changelog as "reported by a community member" unless you ask for your name to be listed.
