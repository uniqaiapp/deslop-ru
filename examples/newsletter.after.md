Version 4.2 is out. Three changes you will notice:

Slack and Linear now sync both ways. Close a task in either place and it closes in the other within a minute. Setup is one screen under Settings, Integrations.

Automations can run on a schedule. The most requested one, "move stale tasks to review every Friday", is a template now.

The dashboard loads the last 90 days by default instead of all time. For the full history, change the range once; it is remembered per board.

Known issue: the mobile app does not show scheduled automations until the next release, planned for two weeks from now.
