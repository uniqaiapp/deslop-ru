Как поставить deslop-ru в Claude Code, Cursor и Codex

Три способа подключить скилл и четыре команды чекера. Зависимостей нет, нужен только Python.

Обновлено 26.11.2026 · Автор: Vlad Yasinski (LinkedIn, roimobi.com) · Код на GitHub

Проверить текст

Как установить deslop-ru?

Скопируйте репозиторий в папку скиллов Claude Code, положите правило deslop-ru.mdc в проект Cursor или добавьте блок из codex/INSTRUCTIONS.md в AGENTS.md для Codex. Скрипту нужен только Python 3.9 и новее, ставить пакеты не надо. Потом скажите агенту убрать ИИ-штампы и укажите файл.

Claude Code

Скилл ставится в папку скиллов. Для всех проектов:

git clone https://github.com/uniqaiapp/deslop-ru ~/.claude/skills/deslop-ru

Только для одного проекта:

git clone https://github.com/uniqaiapp/deslop-ru .claude/skills/deslop-ru

Или через каталог скиллов:

npx skills add uniqaiapp/deslop-ru

Через плагин: сначала добавьте каталог, потом поставьте скилл.

/plugin marketplace add uniqaiapp/skills
/plugin install deslop-ru@uniqaiapp

Дальше напишите /deslop-ru или попросите: «убрать ИИ-штампы из этого файла».

Cursor

Скопируйте .cursor/rules/deslop-ru.mdc в папку .cursor/rules/ проекта вместе с SKILL.md, scripts/ и references/. Правило подключает скилл через @SKILL.md.

Codex и другие агенты с AGENTS.md

Скопируйте SKILL.md, scripts/ и references/ в .agents/skills/deslop-ru/ и добавьте блок из codex/INSTRUCTIONS.md в свой AGENTS.md. Блок просит агента запускать проверку до и после правки и сообщать оценку:

python3 .agents/skills/deslop-ru/scripts/deslop.py check <файл>

Без агента: командная строка и CI

Скрипту нужен только Python 3.9 и новее. Четыре команды:

python3 scripts/deslop.py check текст.md    # находки с номерами строк и оценка
python3 scripts/deslop.py audit текст.md    # разбор по категориям и метрики формы
python3 scripts/deslop.py strip текст.md    # безопасная вычистка, печатает результат
python3 scripts/deslop.py stats             # сколько шаблонов в каждой категории

В CI поставьте порог по оценке: сборка упадёт, если текст набрал больше 20.

python3 scripts/deslop.py check --fail-over 20 docs/*.md

Сначала проверьте в браузере

Не хотите ничего ставить? Та же проверка работает на главной странице без установки.
